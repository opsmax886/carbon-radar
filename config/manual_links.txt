# ============================================================
# 手动链接池
# ------------------------------------------------------------
# 用途:把无法自动抓取的文章(尤其是微信公众号)手动补进来。
#
# 为什么微信要手动?
#   经实测,微信【只开放单篇文章页】,不开放任何"文章列表"接口:
#     · profile_ext 历史列表 → 返回 {"ret":-3,"errmsg":"no session"} 必须登录态
#     · 合集 album 接口      → 返回 ret:10004
#     · 搜狗微信             → 会话绑定 + JS 反爬,解不出真实链接
#   而单篇文章页(https://mp.weixin.qq.com/s/xxxx)是完全公开可读的,
#   所以"贴链接"是当下唯一稳定、免费、零维护的办法。
#
# ------------------------------------------------------------
# 怎么用(以微信公众号为例)
# ------------------------------------------------------------
# 1. 微信里打开文章 → 右上角「⋯」→「复制链接」
# 2. 回到本文件,在下面「我的链接」区域新增一行,把链接粘进去
# 3. 保存。次日早上 9 点系统自动抓取标题、公众号名、发布时间,
#    跑关键词打分和 AI 摘要,并入看板和钉钉推送。
#
# 想让同事也能投稿?把本文档在 GitHub 上的链接发给他们,
# 他们用网页版 GitHub 点铅笔图标就能加(需要仓库写权限)。
#
# ------------------------------------------------------------
# 规则
# ------------------------------------------------------------
# · 一行一个链接
# · 以 # 开头的行是注释,不会被抓取
# · 可以加标签指定归类,不写则自动判断:
#     #tender      招投标
#     #policy      政策法规
#     #methodology 方法学/标准
#     #news        市场动态(默认)
#   写法示例:
#     https://mp.weixin.qq.com/s/xxxxx #tender
#
# · 抓取过的链接会记在 data/manual_cache.json,不会重复抓取
# · 想删掉某条:直接删掉这一行即可(已进入历史的内容不会消失)
# ============================================================
